# NariShop

Интернет-магазин электроники и бытовой техники для Узбекистана. Сейчас это витрина на demo-данных: каталог, карточка товара, корзина и оформление заказа работают без базы данных.

Требования и план: [PRD.md](PRD.md), [Spec.md](Spec.md), [Task.md](Task.md).

## Запуск

Нужен Node.js 22.12+.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Сайт откроется на http://localhost:3000 и перенаправит на `/ru` (или на язык, выбранный ранее: `/uz`, `/en`).

## Структура

```
src/
  app/[locale]/        страницы: главная, каталог, товар, корзина, checkout, инфо
  app/api/v1/          API: categories, products, cart/quote, orders
  components/          UI, layout, каталог, товар, корзина
  features/            схемы Zod, корзина (zustand), параметры каталога
  lib/                 i18n, форматирование денег, утилиты
  messages/            словари uz / ru / en
  server/demo/         demo-каталог
  server/repositories/ доступ к данным каталога
  server/services/     расчёт корзины и создание заказа
  proxy.ts             редирект на язык
  tests/               тесты Vitest
```

## Demo-режим и ограничения

- Товары, бренды, цены и остатки вымышлены; на сайте показывается баннер demo-версии.
- Фото товаров сгенерированы (`public/products/*.webp`) и не изображают реальные модели.
- Заказы хранятся в памяти процесса и пропадают после перезапуска.
- Язык по умолчанию — `ru`; язык браузера не учитывается, выбор пользователя хранится в cookie `NEXT_LOCALE`.
- Тексты инфо-страниц — черновики, их нужно согласовать.
- Несуществующий slug категории или товара показывает страницу 404, но со статусом 200 (ограничение `cacheComponents` в Next.js 16).

## Переход на Neon

Данные каталога читаются только через `src/server/repositories/catalog.ts`, заказы создаются в `src/server/services/orders.ts`. Для подключения Neon нужно заменить реализацию этих модулей на запросы Drizzle и заполнить `DATABASE_URL` / `DATABASE_URL_UNPOOLED`. Страницы и API менять не придётся.
