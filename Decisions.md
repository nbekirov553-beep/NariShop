# Decisions — продуктовые решения (T-001)

Реестр решений по магазину. **✅ Принято** — используется в коде; **❓ Не утверждено** — нужна информация от владельца, до утверждения в коде стоит заглушка или черновик.

Обновлено: 2026-10-26.

## Принятые решения

| Тема | Решение | Где в коде |
|---|---|---|
| ✅ Название | NariShop (знак «nari / shop.») | `src/lib/brand.ts` |
| ✅ Рынок и валюта | Узбекистан, суммы в UZS целыми числами | `src/lib/money.ts`, колонки `*_uzs` в БД |
| ✅ Языки | uz / ru / en, URL `/uz`, `/ru`, `/en` | `src/lib/i18n/config.ts`, `src/messages/*` |
| ✅ Язык по умолчанию | `ru`; выбор пользователя хранится в cookie `NEXT_LOCALE` | `src/proxy.ts` |
| ✅ Темы | светлая / тёмная / как в системе, выбор хранится в браузере | `theme-switcher.tsx` |
| ✅ Категории MVP | Смартфоны, Ноутбуки, Планшеты, Телевизоры, Наушники и колонки, Бытовая техника | `src/server/demo/catalog-data.ts` → таблица `categories` |
| ✅ Статусы заказа | `pending`, `confirmed`, `processing`, `shipped`, `completed`, `cancelled` | enum `order_status` в БД |
| ✅ Статусы платежа | `not_started`, `pending`, `paid`, `failed`, `refunded` | enum `payment_status` в БД |
| ✅ Оплата в MVP | при получении (наличные или карта курьеру) и картой онлайн через Stripe Checkout (пока тестовый режим); неоплаченный онлайн-заказ отменяется через 1 час | `src/server/payments`, `/api/v1/webhooks/stripe` |
| ✅ Способы получения | курьер и самовывоз | форма оформления заказа |
| ✅ БД | Neon (PostgreSQL) + Drizzle; локально без `DATABASE_URL` — встроенный PGlite | `src/server/db/*` |
| ✅ Дизайн | текущий дизайн принят владельцем | — |
| ✅ Вход | Google через Auth.js, сессии в БД; email-вход — после выбора почтового сервиса | `src/server/auth.ts` |
| ✅ Роли | `customer` / `manager` (заказы) / `admin` (всё); админы задаются `ADMIN_EMAILS` | `src/server/permissions.ts` |
| ✅ Удаление товара | только архив: товар скрывается с витрины, история заказов сохраняется | `setProductActive` в `catalog-admin.ts` |
| ✅ Отмена заказа | товары возвращаются на склад; завершённый заказ отменить нельзя | `changeOrderStatus` в `orders.ts` |
| ✅ Номер заказа | `NS-100001` и далее (последовательность в БД) | `order_number_seq` |
| ✅ Хостинг | Vercel, адрес `https://nari-shop-tau.vercel.app`; webhook Stripe — `/api/v1/webhooks/stripe` | переменные окружения — в настройках проекта Vercel |
| ✅ Онлайн-провайдер | только Stripe (ЮKassa исключена владельцем); сумма в UZS, в Stripe — в тийинах (× 100) | `src/server/payments/stripe.ts` |
| ✅ Telegram Mini App | Тот же сайт внутри Telegram, вход по init data: подпись проверяет сервер токеном бота, данные старше часа не принимаются; Telegram-аккаунт привязывается к уже вошедшему пользователю или создаёт покупателя; cookie сессии из Mini App — `SameSite=None; Secure` (Telegram Web открывает сайт во фрейме) | `src/server/telegram.ts`, `src/server/services/telegram.ts`, `/api/v1/telegram/session`, `/{locale}/tg` |
| ✅ Курс доллара | `USD_UZS_RATE` (сумов за 1 $) — только справочно: «≈ $X» в оформлении, на странице Stripe и в админке; списание всегда в сумах, курс на момент оплаты пишется в метаданные платежа Stripe | `src/lib/money.ts`, `src/server/fx.ts` |
| ✅ Профиль покупателя | имя, фамилия, телефон, дата рождения, город и адрес; контакты и адрес подставляются в оформление заказа | `src/features/profile/schema.ts`, `src/server/services/users.ts` |
| ✅ Фото профиля | обрезается в браузере до 256×256 и хранится в БД (таблица `user_avatars`, ~20 КБ) до появления S3; JPG/PNG/WebP проверяются по сигнатуре файла | `/api/v1/avatars/[userId]` |

## Не утверждено (нужен ответ владельца)

| Тема | Что нужно | Что сейчас на сайте |
|---|---|---|
| ❓ Реальные товары и цены | ассортимент, SKU, цены, остатки | demo-каталог с вымышленными брендами и баннер «Демо-версия» |
| ❓ Доставка | города, сроки, стоимость, бесплатный порог | черновик: «условия будут опубликованы после утверждения»; `delivery_fee_uzs = 0` |
| ❓ Возврат и обмен | сроки и порядок возврата | черновик со ссылкой на законодательство РУз |
| ❓ Гарантия | адреса сервисных центров | черновик; срок гарантии — в карточке товара (demo) |
| ❓ Контакты | телефон, адрес, часы работы, мессенджеры | черновик «появятся после утверждения» |
| ❓ Политика конфиденциальности и оферта | юридически проверенные тексты | черновик |
| ❓ Домен | собственный домен для production | сайт на Vercel: `nari-shop-tau.vercel.app` |
| ❓ Аккаунт Stripe | юрлицо и страна, на которые открывается аккаунт (компании из Узбекистана Stripe не обслуживает), тестовые ключи | не получены |
| ❓ Почтовый сервис | провайдер для писем (Resend, SMTP и т. п.) | email-вход и смена пароля не сделаны |
| ❓ Хранилище фото | S3-совместимый бакет | фото товара задаётся ссылкой; фото профиля временно хранится в БД |

Тексты инфо-страниц помечены на сайте плашкой «Черновик» (`info.draft` в словарях), пока владелец их не утвердит.
